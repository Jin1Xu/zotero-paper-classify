# Zotero 主线论文归类

将 Zotero「未分类条目」中的论文归入个人文库的「主线论文」。Skill 会读取当前集合树，对照各类别的代表论文，按论文的主要研究问题、输出和实验选择最贴切的类别。

## 在 Codex 中使用

| 目的 | 示例 |
| --- | --- |
| 预览归类方案 | `$zotero-paper-classify 预览未分类论文的归类方案` |
| 执行归类并核验 | `$zotero-paper-classify 将未分类论文归入主线论文` |

可以指定论文标题或批次。省略范围时检查全部未分类论文。

## 归类规则

- 优先复用最贴切的已有子集合，每篇论文默认选择一个主归属。
- 当主题属于主线范围、现有类别无法自然覆盖、与相邻类别的边界清楚且有长期检索价值时，才新建子集合。新类沿用同级类别的命名风格和粒度。
- 证据不足、归属有实质歧义或超出主线范围时，暂留未分类并说明原因。

归类结果按集合路径汇总，附简短依据，并列出新建集合和暂留未分类的论文。详细规则见 [SKILL.md](SKILL.md)。
